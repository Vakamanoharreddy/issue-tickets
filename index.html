Flask Ticketing App

This repository contains a Flask application that uses templates under Template/requirement and static assets under static/.

Important: GitHub Pages cannot run Flask. The real app must be hosted on a Python-capable service.

Option 1: Deploy as a Flask app

Use a Python host such as Railway, Render, Heroku, or PythonAnywhere.

  • requirements.txt
  • Procfile
  • runtime.txt

Option 2: Use GitHub Pages static landing page

If you want GitHub Pages, point Pages to the repository root or the docs/ folder and this static page will be served.

  1. Open GitHub repo settings.
  2. Go to Pages.
  3. Select branch main and folder /root or /docs.
  4. Save and wait for the site to build.
