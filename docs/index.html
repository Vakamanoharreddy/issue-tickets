GitHub Pages Deployment

This repository contains a Flask application that requires a Python server environment. GitHub Pages is only for static HTML/CSS/JS sites, so it cannot run the full backend app.

Result: If you enable GitHub Pages without a static entrypoint, you will get a 404 error.

Option 1: Deploy the Flask app to a Python host

Use a platform such as Railway, Render, PythonAnywhere, or Heroku. This repository now includes:

  • requirements.txt
  • Procfile
  • runtime.txt

On those hosts, deploy the repo and point the web process to file:app.

Option 2: Use this static landing page for GitHub Pages

If you want GitHub Pages, set the Pages source to the docs/ folder in repository settings. This page will serve instead of a 404.

To use GitHub Pages with this repo:

  1. Open GitHub repo settings.
  2. Go to Pages.
  3. Select branch main and folder /docs.
  4. Save and wait a few minutes for deployment.

Note: This static page only documents the app, it does not run the Flask server.
